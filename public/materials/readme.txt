Сборник практик (архив)
=======================

После сборки статический файл `sborniki-praktik.zip` должен лежать в этой папке (или замените
ссылку через переменную `VITE_PRACTICES_MATERIALS_URL` для внешнего CDN).

Страница сборника включает скачивание после возврата с успешной оплаты (?pay=ok).
Доступ только на стороне браузера; при необходимости замените zip на финальный файл.
